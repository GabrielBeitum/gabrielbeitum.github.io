# gabrielbeitum.github.io

Site público do **@gabrielbeitum.ai**, publicado pelo GitHub Pages em https://gabrielbeitum.github.io.

Hoje ele hospeda as páginas públicas que a Meta exige para o app **Gabrielbeitum.ai**. O app é de uso privado e funciona só no perfil @gabrielbeitum.ai do Instagram.

## Páginas

| Página | Link | Arquivo |
|---|---|---|
| Início | https://gabrielbeitum.github.io/ | `index.html` |
| Política de Privacidade | https://gabrielbeitum.github.io/privacidade.html | `privacidade.html` |
| Instruções de exclusão de dados | https://gabrielbeitum.github.io/exclusao-de-dados.html | `exclusao-de-dados.html` |

O arquivo `.nojekyll` faz o GitHub Pages servir os HTML como estão, sem processar nada.

## Onde ver o link do site no GitHub

- **Settings → Pages:** no topo aparece "Your site is live at https://gabrielbeitum.github.io/", com o botão **Visit site**. No celular, abra o GitHub no navegador com a opção "Site para computador" para ver a aba **Settings**.
- **Página inicial do repositório:** na coluna da direita, em **Deployments**, clique em **github-pages** para ver o link e o histórico de publicações.
- **Este README:** a tabela acima tem os três links.
- **Atalho opcional:** na coluna da direita, clique na engrenagem ⚙ ao lado de **About** e marque **Use your GitHub Pages website**. O link passa a aparecer no topo do repositório.

## Como atualizar

1. Os textos são mantidos no repositório privado da empresa: a Seção 1 escreve e a Seção 3 gera os HTML.
2. O dono aprova a nova versão.
3. Os HTML gerados substituem os desta pasta, com a nova data de vigência.

Os endereços não mudam. Não edite os HTML direto aqui: assim o texto aprovado e o publicado continuam iguais.

- Toda mudança no ar passa pela aprovação do dono.
