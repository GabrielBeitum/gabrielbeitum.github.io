# gabrielbeitum.github.io

Site público do **@gabrielbeitum.ai**, publicado pelo GitHub Pages em https://gabrielbeitum.github.io.

Ele tem a página inicial, com a apresentação do Gabriel e os serviços, e as páginas públicas que a Meta exige para o app **Gabrielbeitum.ai**. O app é de uso privado e funciona só no perfil @gabrielbeitum.ai do Instagram.

O arquivo `.nojekyll` faz o GitHub Pages servir os HTML como estão, sem processar nada.

## Como atualizar

1. Os textos da política, da exclusão de dados e dos termos são mantidos no repositório privado da empresa: a Seção 1 escreve e a Seção 3 gera os HTML. A página inicial (`index.html`) e as imagens em `img/` são editadas direto aqui.
2. O dono aprova a nova versão.
3. Os HTML gerados substituem os desta pasta, com a nova data de vigência.

Os endereços não mudam. Não edite direto aqui os HTML da política, da exclusão de dados e dos termos: assim o texto aprovado e o publicado continuam iguais.
